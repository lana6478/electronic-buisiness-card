# Shopping list

Links to buy every part. The **AliExpress** links are cheapest (2–3 week
delivery). **Amazon UK** and **eBay UK** cost more but arrive in days.

The links are **searches** rather than single listings, because
AliExpress listings change and disappear all the time. Check each listing
against the notes column before you buy.
